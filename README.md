## 🚀 Progetti

### 🏙️ Smart Mobility: piattaforma di mobilità urbana condivisa
Progetto del corso di Ingegneria del Software (a.a. 2025-2026), sviluppato in team di quattro persone con metodologia **Scrum**. Una piattaforma di mobilità condivisa per una città fittizia.

- **Architettura a livelli** Client-Server / MVC: frontend **React**, controller **FastAPI**, business logic layer, data access layer con **SQLAlchemy**
- **Progettazione**: diagrammi UML delle classi e dei componenti, valutazione delle user story, report di sprint
- **Stack**: `React` · `FastAPI` · `SQLAlchemy` · `Python`
